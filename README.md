# 2026 陕西电赛 E 题 · 拼图装置

与朋友共同开展的拼图装置复现与调试项目。装置通过摄像头识别拼图片的几何轮廓、计算摆放位置与旋转角度，再由 STM32 控制平面运动、升降、旋转和电磁铁取放，完成拼接。

我主要负责嵌入式控制、视觉算法，以及视觉端与下位机之间的通信协调。当前实物完成情况由本人和队友进行自测；本仓库不将自测评价作为正式比赛获奖记录。

## 如何打开

1. 在 Keil MDK 中打开 `program/STM32/MDK-ARM/aaaaaaaaa.uvprojx`。工程目标为 STM32F103C8，原配置使用 ARM Compiler 5；安装对应芯片支持包及工具链后再编译。CubeMX 配置保留在 `program/STM32/aaaaaaaaa.ioc`。
2. 摄像头脚本面向 MaixCAM / MaixPy v4，使用 `maix`、OpenCV 和 NumPy。应在匹配的开发板环境部署，桌面 Python 不能直接替代摄像头运行环境。
3. 按电路图核对实际接线，结合机械尺寸调整相机位置、坐标方向、每厘米脉冲数及取放偏移。材料清单按原文件保留，实际器件以电路与实物为准；视觉端硬件也需单独核对。

原始 C 文件部分使用 GB18030/GBK 编码，已保留文件字节和换行。若中文注释乱码，请在编辑器中选择对应编码，不要直接覆盖保存。
